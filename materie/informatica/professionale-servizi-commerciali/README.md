# Informatica nei Servizi commerciali

Triennio del professionale Servizi commerciali. Il quadro 3F prevede Informatica A-41 con intervallo 0-99 ore per ciascun anno: l’effettiva attivazione e il peso dipendono dal curricolo d’istituto. Nel biennio si può usare il percorso TIC dei professionali.
