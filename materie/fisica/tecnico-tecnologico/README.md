# Istituto tecnico tecnologico-ambientale

Scienze sperimentali · componente fisica · A-20 con A-34 e A-50 · anni 1-2.

La riforma è progressiva per coorte. La prima classe entra nel 2026/27 e la seconda entra nel 2027/28. I nuclei comuni del nuovo settore tecnologico-ambientale si adattano all’indirizzo. Per le seconde tecnologiche del 2026/27 il nome è ancora Scienze integrate (Fisica), con riferimento alla direttiva del 2010. Nel vecchio indirizzo agrario la tabella A-27 contiene un’attribuzione ad esaurimento. Le schede distinguono le due coorti.
