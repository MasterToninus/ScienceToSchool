# Istituto professionale, arti ausiliarie delle professioni sanitarie, Ottico

Ottica, ottica applicata · A-20 · anni 1-5.

Questa disciplina si affianca a Scienze integrate del biennio. Concordare con i laboratori di indirizzo gli strumenti effettivamente disponibili. Le esercitazioni trattano sistemi ottici e misure su banco.
